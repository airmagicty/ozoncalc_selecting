Скрипт-дополнение для озон-калькулятора, добавляющий функционал подбора конечного значения после пересчетов в пару итераций. Введите нужный артикул, напишите желаемую цену и алгоритм сам подберет ближайшую цену в изначальных параметров, чтобы после пересчетов сумма была близка к заданной. Одно нажатие - одна итерация
